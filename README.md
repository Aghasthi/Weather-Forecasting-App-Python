# 🌦️ Weather Forecasting App

A Python-based weather forecasting application that uses the OpenWeather API to provide real-time weather information and 5-day forecasts for cities.

##  Features

- Real-time temperature and feels-like temperature
- Current weather condition
- Humidity information
- Wind speed
- Atmospheric pressure
- Sunrise and sunset timings
- 5-day weather forecast
- Search weather by city name
- Interactive web interface using Gradio
- Error handling for invalid city names and API errors

##  Technologies Used

- Python
- Gradio
- OpenWeather API
- Requests
- Pandas
